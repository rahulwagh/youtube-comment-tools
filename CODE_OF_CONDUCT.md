# Code of Conduct

Be kind, be specific, assume good intent. Disagree about code, not about people.

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Harassment, insults and personal attacks are not accepted in issues, pull requests or any other project space.

Report problems to contact@replydial.com. Reports are handled privately.
